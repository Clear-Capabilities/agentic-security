## Limitations

- One small fixture per language: absence here is not absence in a real framework variant.
- `detected` for a control means the extractor reported that control kind on that route; it does not say the control is effective.
- Confidence and limitation per claim are carried in each bundle manifest at run time; this audit is the static view of the same facts.
