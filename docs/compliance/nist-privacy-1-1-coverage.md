# NIST Privacy Framework 1.1 scanner coverage map

**Framework version:** NIST Privacy Framework 1.1 — 104 controls across five Functions

This table maps every PF 1.1 control to the scanner signal that provides evidence for it, or
marks it as an **engine gap** (NIST rates the control code-testable, but this engine produces no
signal for it) or **out of scope** (the control is organisational/process — no code artefact can
attest it).

Automated technical-control evidence is generated by `agentic-security compliance` (also
`/compliance --privacy`), which writes `.agentic-security/privacy-framework.{json,md}`. It reads
the last scan rather than re-scanning, exits **2** when there is no scan to assess, and exits **1**
only with `--fail-on gap`. Gaps are emitted as ordinary findings (`family: privacy-compliance`).

> Each control carries NIST's own `codeTestable` rating (yes/partial/no). That rating says whether a control COULD be assessed from source code — it does not say this engine assesses it. `mapsTo` is present only where this engine produces a real signal; a control that NIST rates testable but which this engine cannot see is reported as an ENGINE GAP rather than silently passed.

**Source of truth:** `scanner/src/posture/compliance-frameworks/nist-privacy-1-1.json`, which holds
the control text and `codeTestable` ratings transcribed from NIST Privacy Framework 1.1
(<https://www.nist.gov/privacy-framework>). That JSON is authoritative here; the source workbook is
not kept in this repository. This document is derived from the JSON — regenerate it when the JSON
changes rather than editing the tables by hand.

## Status legend

| Status | Meaning |
|---|---|
| **Covered** | `codeTestable: yes` **and** the engine maps a real signal to it. |
| **Partial** | The engine maps a signal, but NIST rates the control only partially code-testable — automated evidence is necessary, not sufficient. |
| **Engine gap** | NIST rates it testable (`yes`/`partial`) but this engine produces no signal. Reported as a gap, never silently passed. |
| **Out of scope** | `codeTestable: no` — requires human attestation. |
