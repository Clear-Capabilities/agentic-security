## Stage navigation

Within any lifecycle page, show the ten stages as a persistent rail: Discover, Corroborate, Prove, Learn, Scale, Observe, Trace, Fix, Verify, Detect. Each stage shows its stage maturity text (for example "Roadmap" on Detect). Order never varies.

## Two-click rule

From the docs home, every role reaches its core workflow in two clicks: the role page (one), then its "Core workflow" link (two). The documentation checker enforces this for the docs, and the site must keep it.

## Breadcrumbs

`Docs / <Area> / <Page>`. The area is one of: Quickstart, How it works, the ten stage names, Security graph, Trust, Roles, Workflows, Integrations, Reference, Labs, Roadmap.
